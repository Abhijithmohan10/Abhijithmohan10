### 🎨 Animation Concept

```text
             ┌───────────────────────┐
             │       ABHIJITH        │
             │          ✦            │
             │   SOFTWARE DEVELOPER  │
             └───────────┬───────────┘

              │                     │

```

The animation can be generated using:

```javascript
anime({
    targets: '.hero-title',
    translateY: [-50, 0],
    opacity: [0, 1],
    duration: 1200,
    easing: 'easeOutExpo'
});

anime({
    targets: '.hero-circle',
    scale: [0, 1],
    opacity: [0, 1],
    duration: 1500,
    easing: 'easeOutElastic(1, .6)'
});
```
